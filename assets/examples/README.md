# Example inputs

These original AI-generated reference images are the inputs for the public AniSora examples. They were created for this deployment, rather than taken from a third-party character franchise or Sprute character assets.

- `fox.png`: photoreal wildlife-style fox; prompted motion is a gentle head turn.
- `explorer.png`: illustrated space explorer; prompted motion is a greeting wave.

The images are committed so anyone can preview and rerun the examples without access to a private upload URL. Public example runs use MP4 output at quality 80, with PNG ZIP output disabled.
